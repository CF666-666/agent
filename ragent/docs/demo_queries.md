## 用例 1：高炉冷却壁漏水如何处理

**查询**：高炉冷却壁漏水如何处理

**行业**：钢铁冶金

**预期命中**：
- 文本检索：FAQ 匹配（高炉冷却壁相关问答）
- 超图检索：高炉故障链超边（equipment="高炉", fault="冷却壁漏水"）

**验证要点**：
- [ ] SSE events: meta → message → finish → done 顺序正确
- [ ] 日志出现 "多通道检索统计" 含 VECTOR_GLOBAL + HYPERGRAPH 通道
- [ ] 答案含具体参数（如温差阈值、冷却水压力）
