## 排序规则

关系路径依次按不同查询实体覆盖数降序、跳数升序、实体类型权重降序和稳定 edge key 升序排列。两跳候选不再因存在第二条边而无条件加分；单实体查询优先紧凑单边，真正覆盖两个查询端点的两跳路径优先。候选生成、最多两跳、取消传播和读锁边界保持不变。
